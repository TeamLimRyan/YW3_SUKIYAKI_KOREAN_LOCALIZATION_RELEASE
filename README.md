## 아직 배포하지 않는 이유

현재 이미지 포함 최종 빌드의 전 구간 런타임 검수가 남아 있고, 개발용 전체 재빌드 아카이브에는 원본 게임 데이터가 포함됩니다. 공개 릴리스에는 원본을 포함하지 않는 차분 패치 또는 오프라인 패처가 필요합니다.

CIA, ROM, 키, 펌웨어, 원본 게임 데이터는 제공하지 않습니다. 사용자는 정품 게임을 합법적으로 보유하고 자신의 환경에서 필요한 입력을 준비해야 합니다.

설치 파일이 준비되기 전에는 [설치 안내](INSTALL_KO.md)의 대기 상태를 확인해 주세요.
