## 배포 및 검증 범위

개발용 전체 재빌드 아카이브는 배포하지 않습니다. 공개 릴리스는 지원 원본을 확인한 뒤 변경분만 적용하는 오프라인 패처 형식입니다. 패치 생성·왕복 해시·아카이브 재파싱 검증을 통과했습니다. 런타임 검수 범위와 미검수 구간은 [호환성](COMPATIBILITY_KO.md)과 [알려진 제한](KNOWN_ISSUES_KO.md)에 공개합니다.

CIA, ROM, 키, 펌웨어, 원본 게임 데이터는 제공하지 않습니다. 사용자는 정품 게임을 합법적으로 보유하고 자신의 환경에서 필요한 입력을 준비해야 합니다.

배포 파일은 GitHub Releases의 `YW3S_Korean_Patch_v0.1.0.zip`입니다. 파일 크기는 49,281,760바이트이고 SHA-256은 `672EEB78E77AC09CA53935B1B2029FED6F58ECFD920FE296189530FE630A38E8`입니다. 사용법은 [설치 안내](INSTALL_KO.md)를 확인해 주세요.
