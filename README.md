## 이번 릴리스에 포함된 작업

- 텍스트 132,357 / 132,357 번역 및 자동 QA 통과
- 한글/영문/기호 페이지가 분리된 조합형 한글 이름 입력
- 4자리 암호 입력 컨텍스트에서 원작의 전각 숫자 `１ ２ ３ ４ ５ ６ ７ ８ ９ ０` 행 복구
- 한글 키보드 입력과 번역문이 같은 런타임 별칭을 사용할 때 요괴 퀴즈 정답을 직접 비교하도록 수정
- 요괴 퀴즈 정답 24종을 게임 전체와 같은 공식 한국어명으로 교정하고, 허용 정답 26개를 키보드와 같은 CP932/PUA 별칭으로 검증
- 전투 UI XPCK를 원본 호환 방식으로 재패킹해 필살기·정화 화면의 비텍스처 동작 데이터를 원본 위치와 바이트로 보존
- 텍스트 검수 사이트의 확정 제출 34건 반영(실제 문구 변경 25건), 미제출 초안 1건 제외
- 기존 이미지 1,685개를 기준으로 식자 제출본 212개 반영(직전 공개본보다 21개 갱신)
  - 기존 반영 이미지 교체: 205개
  - 기존 제외 이미지 신규 포함: 7개
  - 최종 포함 이미지: 1,692개
- 이미지·텍스트·글꼴·입력 스크립트를 포함한 v0.2.0 아카이브 정적 재빌드 검증 통과

새 식자본 212개는 검수 페이지에서 모두 `SUBMITTED` 상태인 최신 스냅샷입니다. 소유자의 배포 지시에 따라 v0.2.0에 포함했으며, 항목별 상태는 검수 이력 보존을 위해 유지합니다.

## 배포 및 검증 범위

개발용 전체 재빌드 아카이브는 배포하지 않습니다. 공개 릴리스는 지원 원본을 확인한 뒤 변경분만 적용하는 오프라인 패처 형식입니다. 패치 생성·왕복 해시·아카이브 재파싱 검증 결과를 릴리스 자산에 고정했습니다.

CIA, ROM, 키, 펌웨어, 원본 게임 데이터는 제공하지 않습니다. 사용자는 정품 게임을 합법적으로 보유하고 자신의 환경에서 필요한 입력을 준비해야 합니다.

배포 파일은 [GitHub Releases](https://github.com/TeamLimRyan/YW3_SUKIYAKI_KOREAN_LOCALIZATION_RELEASE/releases/tag/v0.2.0)의 `YW3S_Korean_Patch_v0.2.0.zip`입니다. 파일 크기는 65,089,135바이트이고 SHA-256은 `02C93EC781810A9461951AF331D9EB2F44AF93F44C0794DF04BCE2CAE3920D29`입니다. 사용법은 [설치 안내](INSTALL_KO.md)를 확인해 주세요.
